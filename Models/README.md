# 3D models for the Parikrama site

Drop generated models here.

- `glb/`  — preferred. GLB carries geometry + materials in one file.
- `obj/`  — fallback. Keep the .obj and .mtl together, same basename.

## Naming — this matters, the build script matches on it

harmandir.glb        the shrine alone, no platform or water
deori.glb            the Darshani Deori gateway
akal-takht.glb       the Akal Takht
bunga-tall.glb       three-storey bunga
bunga-mid.glb        two-storey bunga
bunga-low.glb        single-storey bunga
shaheedan.glb        Shaheedan da Bunga (the hero one)
ramgarhia.glb        the Ramgarhia block + twin minars
